# Фото по помещениям

Это каталог копий: папка Чертежи квартиры остаётся исходным архивом и не изменяется. Одна фотография может повторяться в нескольких папках, если является источником для нескольких помещений.

| Папка | Состав |
| --- | --- |
| 00_Общие | схема взаимного расположения, сводный эскиз, общие правила дома |
| 01_Кухня-гостиная | S03, S10, S12 |
| 02_Детская | S10 и фотографии окна/радиатора |
| 03_Прихожая | S09, общий вид и щит |
| 04_Коридор | S06 |
| 05_Спальня | S02, S04 и фото окна/радиатора |
| 06_Ванная | F09–F20 |
| 07_Туалет | S05, F21–F25, F27 |
| 08_Гардеробная | S07 |
| 09_Терраса | S01 и S12 |
| 10_Инженерия_и_оборудование | тематические копии: розетки, щит, радиаторы, ванная, туалет, вентиляция |

Полная расшифровка чисел и ссылки на первичные JPG находятся в docs/04_Цифровая_ведомость_обмеров_v1.md; список окон и дверей — в docs/07_Ведомость_проемов_и_окон.md; инженерные точки и оборудование — в docs/08_Ведомость_инженерных_точек_и_оборудования.md.
