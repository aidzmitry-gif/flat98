# TV-001 - ревизия столовой зоны на 4 человека (rev4)

## Принятое решение

Стол-трансформер имеет два честно разделённых режима:

- **обычный день:** сложен в консоль `1200x250` у нижней стены слева от ТВ; проход D2 -> O1 остаётся чистым `900` мм;
- **обед на 4:** стол `1200x700` переносится в центральное поле и ставится по общей оси диван - ТВ. Четыре складных стула `400x450` стоят по два с каждой длинной стороны.

## Проверенные расстояния

| Проверка | Значение | Статус |
| --- | ---: | --- |
| Центр дивана / ТВ / стола | `3410` мм от левой стены B01 | совпадают |
| Стол | `1200x700` мм | 4 места |
| Стул | не больше `400x450` мм | 2+2 по длинным сторонам |
| Верхние стулья -> диван | `100` мм | технический зазор, не проход |
| Левая ветвь кухни и ПММ | свободна | мебель стола не входит в рабочие зоны кухни |
| D2 -> O1 во время обеда | временно занят нижними стульями | допустимо только на время еды |
| D2 -> O1 в обычном/ночном режиме | `900` мм | свободен |
| Правая фасадная стена | `3500` мм | одна прямая: `1300 + O1 1600 + 600` |

## Ограничения к покупке

1. Нужен один лёгкий стол-трансформер на колёсах или с безопасным переносом: сложен не глубже `250` мм, открыт `1200x700` мм, без тяжёлого основания-тумбы.
2. Четыре стула должны складываться; внешний контур каждого не больше `400x450` мм. Полноразмерные кресла в этот режим не входят.
3. Перед заказом проверить реальный путь перемещения стола из нижней консоли в центр, высоту столешницы, механизм и место хранения четырёх сложенных стульев.
4. Обеденный режим не оставляют разложенным постоянно: он забирает основной маршрут к O1. Для ночного режима стол и стулья обязательно убираются.

## Вывод

Четыре полноценных места получаются без доступа к кухне и без смещения ТВ с оси дивана. Компромисс один и явный: во время еды путь к террасе не считается свободным.
