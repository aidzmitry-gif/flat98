# Комната 7 — ведомость заказа и выпуска

Статус документа: реестр допуска к закупке и выпуску строителям. Он не меняет принятую расстановку и не разрешает сверление по эскизным отметкам.

Референсы материалов, оборудования и визуализаций — **не утверждённые SKU, не цены и не обещание наличия**. Для каждой позиции ниже до выпуска обязательны: точный SKU, поставщик, цена, срок поставки, ответственный и монтажная карта выбранного изделия.

## Статусы

- **ПРИНЯТО** — принцип или плановый контур зафиксирован; выпуск только после заполнения карточки позиции.
- **УСЛОВНО** — допускается после контрольного обмера, карты производителя или проверки совместимости.
- **НА ВЫБОР** — модель и образец ещё выбираются; заменять принцип без отдельного решения нельзя.
- **СТОП — НЕ ЗАКАЗЫВАТЬ** — позицию нельзя выпускать, оплачивать или закрывать отделкой до прохождения указанного гейта.

## Обязательные поля карточки любой позиции

| Поле | Заполнить перед выпуском |
|---|---|
| Изделие / SKU | Наименование производителя, точный артикул, цвет / покрытие / комплектация. |
| Поставщик | Компания, контакт, ссылка на предложение. |
| Цена | Цена, валюта, доставка, условия оплаты, дата предложения. |
| Срок | Подтверждённый срок поставки и крайняя дата заказа. |
| Ответственный | Закупщик, кто подтверждает совместимость, кто принимает на объекте. |
| Технические документы | Монтажная карта, паспорт, IP / электроданные при необходимости, гарантия. |
| Приёмка | Фото маркировки, комплектность, отсутствие повреждений, проверка критерия ниже. |

## Выпуск в работу

1. Закупщик сверяет SKU, покрытие, комплектацию, срок и цену с подтверждённым предложением.
2. Прораб сверяет карты монтажа с фактическим обмером, трассами и сервисными зонами.
3. Позиция со статусом **СТОП — НЕ ЗАКАЗЫВАТЬ** остаётся заблокированной до фотофиксации гейта.
4. После плитки повторно обмеряют чистовой пролёт тумбы; только затем выпускают мебель.
5. Крепёж размечают только по реальной модели, монтажной карте и проверенным трассам. Этот документ не содержит монтажных координат и не является разрешением на сверление.
