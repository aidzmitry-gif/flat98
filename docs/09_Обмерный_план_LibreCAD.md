# APT-001 revision 10 — подробный план для LibreCAD

Актуальная редактируемая модель: [04_Подробный_обмерный_план_LibreCAD.dxf](../plans/04_Подробный_обмерный_план_LibreCAD.dxf).

## Открытие и печать

1. В LibreCAD выберите **Файл → Открыть** и укажите актуальный DXF.
2. Выполните **Вид → Автомасштаб**. Модель и лист построены в миллиметрах 1:1.
3. Для печати выберите **A2, альбом**, фиксированный масштаб **1:50**. Не включайте «Подогнать к странице».
4. После печати измерьте шкалу `0–1000 мм`: на бумаге она должна быть ровно `20 мм`.
5. Готовый печатный эталон: [PDF A2, М 1:50](../plans/04_Подробный_обмерный_план_A2_М1_50.pdf).

## Слои revision 10

| Слой | Значение |
| --- | --- |
| `A-WALL-FILL` | Серая заливка подтверждённых внутренних стеновых полос. |
| `A-WALL-OUTLINE` | Контур подтверждённых внутренних стен. |
| `A-EXTERIOR-GRAPHIC` | Наружные и неразмерённые стены: видимая графическая полоса без неподтверждённого числового значения толщины. |
| `A-OPENING` | Подтверждённые окна и открытые проходы. |
| `A-DIM-BTI` | Размеры и цепочки БТИ B01. |
| `A-DIM-CONTROL` | Повторные контрольные обмеры Cxx/U01. |
| `A-TOPOLOGY` | Связность и фрагменты, полный контур которых не замкнут. |
| `A-EQUIPMENT` | Непозиционные условные знаки подтверждённого оборудования. |
| `A-CEILING` | Точечные высоты потолков по углам и в центре. |
| `A-CONFLICT` | Расхождения источников, которые нельзя усреднять. |
| `A-UNKNOWN` | Неизвестные размеры/оси и сегменты, не равные чистому проёму. |
| `A-SHEET`, `A-INSET`, `A-TEXT`, `A-AREA`, `A-SOURCE` | Рамка A2, вставки, подписи, площади и коды источников. |

## Важные ограничения

- D1/D2 имеют контрольные габариты `1140×2150` и `915×2150`, но не имеют надёжных угловых привязок и подтверждённых сторон открывания; D2 связывает непосредственно прихожую 3 с кухней 1.
- Сегменты B01 `710/810/810` у D5/D4/D3 не являются чистой шириной дверей. Для D4 в T01 есть предварительные `705×2027` и подтверждённое открывание наружу, но сторона петель н/д.
- Полный верхний контур коридора не достроен предположениями; два контрольных фрагмента вынесены справа.
- ЭЩ-03 и три розетки E-03 показаны в прихожей на левой стене у входа как зоны с осями н/д. ВМ-07 (короб 360×710 со счётчиками) и Л-07 (локальный щиток/лючок C05) — разные объекты. Радиаторы, розетки кухни, ванная и остальная инженерия остаются непозиционными/локальными.
- Наружная толщина стен на БТИ числом не задана.
