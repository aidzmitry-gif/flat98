# Документы проекта ремонта

**Актуальное решение по полу от 09.11.2026:** [Дуб Синистра в жилых помещениях и отдельный пол в ванной и санузле](ОБЩЕЕ_РЕШЕНИЕ_ПОЛ_Дуб_Синистра_2026-11-09.md).

Эта папка — единый источник актуальных данных по квартире. Каждый новый замер
сначала вносится в реестр, а затем используется в чертежах и подборе решений.

## Состав

- `01_Реестр_обмеров_квартиры.md` — оперативный журнал замеров и открытых
  вопросов по всей квартире.
- `02_Туалет_паспорт_обмеров.docx` — оформленный паспорт исходных данных
  туалета для предварительной планировки.
- `03_Ванная_паспорт_обмеров.docx` — оформленный паспорт стартовых обмеров
  ванной комнаты и список данных для рабочего проекта.
- `09_Обмерный_план_LibreCAD.md` — инструкция к актуальному редактируемому
  DXF revision 13 и его слоям.
- `11_Паспорт_подробного_обмерного_плана.md` — матрица источников, правил
  отображения и неопределённостей APT-001 revision 13.
- `12_Ведомость_размеров_APT-001_revision_2.md` — актуальная ведомость по
  каждому помещению с прямыми ссылками на фотографии-источники.

## Правила статусов

- **Подтверждено** — значение прямо сообщено пользователем или перепроверено.
- **Предварительно** — можно применять для эскиза, но нужно проверить до
  заказа материалов, мебели или работ.
- **Требует уточнения** — не использовать как рабочий размер.
