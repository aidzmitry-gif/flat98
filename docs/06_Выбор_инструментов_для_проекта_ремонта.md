# Выбор инструментов для проекта ремонта

## Принцип

Можно использовать open-source основу, но готовой «типовой квартиры» недостаточно: геометрия, инженерные выводы и ограничения должны строиться по фактическим обмерам.

## Рекомендуемый стек

| Задача | Инструмент | Роль |
| --- | --- | --- |
| Планировка, мебель, быстрый 3D | Sweet Home 3D | Точные размеры, импорт исходного плана, экспорт PDF/SVG/OBJ |
| Строгие 2D-чертежи | LibreCAD | Электрика, сантехника, демонтаж и монтаж |
| BIM и IFC | Bonsai + Blender или FreeCAD BIM | Параметрические стены, IFC, комплект документации |

Для одной квартиры практичный выбор — Sweet Home 3D + LibreCAD. BIM имеет смысл для сложного проекта, большого объёма заказной мебели или дальнейшего использования модели.

## Роль скиллов

Готовые скиллы не заменяют CAD-систему. Они полезны для таблицы бюджета, закупок и спецификаций, технического задания, ведомостей помещений и материалов, PDF-альбома проекта, референсов и концептуальных визуализаций. Специального готового скилла для полноценного CAD-проектирования квартиры нет.

## Рабочая последовательность

```text
Обмеры → Sweet Home 3D → согласование планировки
                         ↓
        LibreCAD → рабочие чертежи → PDF
                         ↓
        таблицы → смета, материалы, закупки
```

## Связь с текущим проектом

Этот проект уже содержит фактические обмеры, ведомость и масштабный план. Sweet Home 3D следует использовать для планировочных вариантов и мебели, а LibreCAD — для выпуска рабочих листов на основе подтверждённых размеров. Контуры без замкнутой размерной цепочки нельзя применять для заказа материалов или мебели до повторного обмера.
